# visualisation-lib

A small, importable plotting library built on matplotlib and pandas.

- **Install name** (pip / PyPI): `viz-lib`
- **Import name** (in Python): `viz_lib`

(As with any package, the install name uses a hyphen and the import name uses
an underscore — `pip install viz-lib`, then `import viz_lib`.)

## Install

```bash
# from a local checkout (editable, for development)
pip install -e .

# once published
pip install viz-lib
```

## Use

```python
import viz_lib as viz

# load a bundled sample dataset (ships inside the package)
df = viz.load_dataset("co2_per_capita")
df = df[df["Year"] == 2024]

viz.ranked_bar(df, category="Entity", value="CO₂ emissions per capita")
```

`ranked_bar` takes any tidy DataFrame, so you can pass your own instead —
e.g. `df = pd.read_csv("your_data.csv")`.

Public API — two plotting functions plus helpers:

| Function | Job | Example chart |
| --- | --- | --- |
| `ranked_bar` | rank a value across items | CO₂ per person by country |
| `stacked_area` | composition over time | US CO₂ by fuel, 1800–2024 |
| `load_dataset` / `datasets` | load a bundled sample CSV | — |
| `apply_theme`, `series_color`, `smog_color`, `PALETTE`, `SMOG` | the shared look | — |

### Bundled datasets

Sample CSVs ship **inside** the package (`viz_lib/data/`) and are read with
`importlib.resources`, so they load whether you run from a checkout or an
installed wheel:

```python
import viz_lib
df = viz_lib.load_dataset("us_co2_by_fuel")   # or "co2_per_capita"
```

## Plots

Plot functions live in `src/viz_lib/`. They share one contract: tidy data plus
role keywords, an optional `ax` for composition, and a returned matplotlib
object. A single theme (`viz_lib.theme`) gives every plot one identity using a
validated, colorblind-safe palette.

### `ranked_bar`

A sorted horizontal bar chart for comparing a value across items. Bars are
sorted by value with the number labelled directly at each bar end, and a
CO₂-themed "smog" color ramp shades them (darker = more emissions).

```python
import pandas as pd
from viz_lib import ranked_bar

df = pd.read_csv("data/raw/co2_per_capita.csv")
df = df[df["Year"] == 2024]

fig = ranked_bar(
    df, category="Entity", value="CO₂ emissions per capita",
    title="A few small, oil-rich nations emit the most CO₂ per person",
    subtitle="Tonnes of CO₂ per person, 2024",
)
```

Pass the same `vmax` to two charts to share one color scale, so a shade means
the same emissions in both. See `notebooks/co2_bars.py` for the two-group example.

### `stacked_area`

Composition over time, with each band labelled directly at its right edge,
for an editorial "hero" chart. See `notebooks/us_co2_hero.py`.

```python
from viz_lib import stacked_area, load_dataset

df = load_dataset("us_co2_by_fuel")
fig = stacked_area(
    df, x="Year", series=["Coal", "Oil", "Gas", "Cement", "Flaring", "Other industry"],
    title="Coal gave way to oil and gas",
)
```

## Project structure

```
├── src/                # the viz_lib library (importable)
├── notebooks/          # example scripts + the Colab notebook
├── tests/              # smoke tests
├── reports/figures/    # generated PNGs (gitignored)
├── docs/               # images + mkdocs site
└── pyproject.toml      # project metadata
```

| Path               | Purpose                                             |
| ------------------ | --------------------------------------------------- |
| `src/`              | The reusable, importable `viz_lib` library.        |
| `notebooks/`        | Example scripts and the Colab presentation notebook.|
| `tests/`            | Smoke tests for the example scripts.               |
| `reports/figures/`  | Graphics generated by the scripts (gitignored).    |
| `docs/`             | README images and the MkDocs site.                 |
| `pyproject.toml`    | Project metadata and build configuration.          |

## Building & installing

```bash
pip install -e .                 # editable install for development
python -m build                  # build a wheel into dist/ (bundles the datasets)
pip install dist/viz_lib-*.whl   # install the built wheel
```

## Data source

The bundled sample datasets are CO₂ and greenhouse-gas figures from the
**Global Carbon Budget (2025)** via
[Our World in Data](https://ourworldindata.org/co2-and-greenhouse-gas-emissions),
licensed **CC BY**.
